# 境外基金開放資料（自動累積）

- 來源：臺灣集中保管結算所 開放資料（境外基金淨值 id=3-4、境外基金配息資訊 id=3-5、境外基金基本資料 id=3-2）
- 授權：政府資料開放授權條款第 1 版，使用時註明「資料來源：臺灣集中保管結算所」
- 更新：GitHub Actions 每天台灣時間 21:17 與 09:43 自動下載
- `raw/日期/`：每天下載的原始檔（不修改）
- `nav.csv`：歷史淨值（依基金代碼＋日期去重）
- `dividend.csv`：配息紀錄
- `basic.csv`：最新基本資料

## map.csv（網站基金 ↔ 集保代碼／ISIN 對照）
- 網站 1,429 檔仍在架的境外基金中，已對到 1,066 檔（信心「高」1,001 檔、「待確認」65 檔）。
- 欄位：網站代碼、網站名稱、集保代碼、ISIN、集保名稱、比對信心、集保風險等級。
- 用集保代碼即可在 nav.csv（淨值）、dividend.csv（配息）找到該基金的資料。
